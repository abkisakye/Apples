# User Training Guide

## Login

- open the system URL
- enter your username or email
- enter your password
- change your password after first login if instructed

## Cashier Daily Flow

1. open dashboard
2. create sale
3. choose customer and items
4. save and print receipt or invoice
5. post customer payments when balances are settled

## Stock Clerk Daily Flow

1. record purchases from suppliers
2. print purchase document if needed
3. review stock balances and reorder report
4. post transfers between stores
5. post stock adjustments when management approves

## Manager Daily Flow

1. check dashboard alerts
2. review overdue credit
3. assign or close follow-ups
4. review statements and aging reports
5. monitor stock alerts

## Admin Tasks

- add or edit users
- reset staff passwords when needed
- review activity logs
- take backups
- coordinate deployment and data imports

## Training Tips

- start with one sale, one payment, and one purchase demo
- print sample documents during training
- explain role limits clearly so staff know why some menus are hidden
- keep the old Access system available for reference during the first training period only
