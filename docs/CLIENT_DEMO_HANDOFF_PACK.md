# Client Demo Handoff Pack

Generated on 21 Apr 2026

## Purpose

Use this pack when sharing the system with a potential buyer for a private demo session.

This is a sales and discovery session, not just technical testing.

## Goal Of The Session

The goal is to help the client quickly see:

- how the system improves cashier work
- how the system improves stock control
- how the owner can follow sales, credit, and reports more clearly
- how the system is better than the old Access style

## Before You Share The Link

1. Confirm the app is running.
2. Confirm the current ngrok/public link is active.
3. Decide which client is receiving the demo.
4. Share only that client's access sheet and message.
5. Do not share `admin`.

Please start with the short demo guide, then go through the normal business flow:

1. review products and stock
2. make one purchase
3. make one sale
4. print a receipt or invoice
5. review statements and reports

As you review the system, please note what you like, what feels unclear, and what you would want improved before real use.

## During The Session

Guide the client toward the strongest value points first:

- sales speed
- stock control
- credit follow-up
- reports for the owner
- cleaner workflow than the old system

## After The Session

1. Record the client's comments in the feedback form.
2. Note what they liked most.
3. Note what blocks them from buying.
4. Note whether they want:
   quotation, more changes, or another session
5. Before the next client session, clean up anything important that could weaken the next demo.

## Important Note

This still uses one shared demo environment.

That means:

- one client should use the system at a time
- the demo data stays in one environment
- you should avoid overlapping sessions
